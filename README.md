# 🧠 Estruturas de Dados em Python 

Este repositório reúne **projetos práticos em Python** desenvolvidos para aplicar conceitos fundamentais de **estruturas de dados**, simulando sistemas simples e interativos.

Os projetos utilizam **fila (FIFO)**, **deque** e **pilha (LIFO)**, com interação direta do usuário via terminal.

---

## 🛠️ Tecnologias Utilizadas

- Python
- collections.deque
- Estruturas de Dados
- Terminal / CLI

---

## 🚗 Projeto 1 — Sistema de Estacionamento (Fila / Deque)

### 📌 Conceito
Simula um estacionamento onde os veículos:
- Entram por **ordem de chegada**
- Saem por **ordem de saída**

### 🧩 Estrutura Utilizada
- `deque` (fila dupla) da biblioteca `collections`

### 🔹 Funcionalidades
- Entrada de veículo
- Saída de veículo (FIFO)
- Visualização do estacionamento
- Sistema interativo via terminal
- Tratamento de estacionamento vazio

### 🧠 Conceitos Aplicados
- Fila (FIFO)
- `deque`
- Laços de repetição
- Condicionais
- Manipulação de estruturas dinâmicas

---

## 📚 Projeto 2 — Sistema de Empilhamento de Livros (Pilha)

### 📌 Conceito
Simula uma pilha de livros onde:
- O **último livro empilhado é o primeiro a ser removido**

### 🧩 Estrutura Utilizada
- Lista (`list`) como pilha

### 🔹 Funcionalidades
- Empilhar livro
- Desempilhar livro (LIFO)
- Visualizar pilha de livros
- Sistema interativo via terminal
- Tratamento de pilha vazia

### 🧠 Conceitos Aplicados
- Pilha (LIFO)
- Métodos `append()` e `pop()`
- Organização visual da pilha
- Interação com o usuário
